# HanAreum MVP 범위

이 문서는 HanAreum MVP에서 우선 구현할 기능과 제외할 기능을 정리한다.

## 1. 우선 구현

- Kakao 기반 장소 검색
- Kakao 지도 표시
- 장소 리스트 표시
- 전역 카테고리 필터: 맛집, 술집, 카페, 서점, 스터디 장소, 가볼만한 곳
- 학교 / 한성대입구역 / 창신역 기준 3-Dot 거리 표시
- 거리순 / 별점순 필터
- 장소 북마크
- 커스텀 폴더 기반 장소 분류
- 리뷰 작성: 별점, 한 줄 평, 좋아요
- 방문 시간대 기반 혼잡도 표시
- 동선 생성: 장소 2개 이상 선택, 동선 이름 입력, 장소 순서 저장
- Kakao 지도 위 동선 Polyline 표시
- 동선 추천 게시판: 공유된 동선 목록, 동선 상세의 장소 순서와 지도 동선, 동선 좋아요
- Supabase Auth 기반 이메일 / 비밀번호 회원가입, 로그인, 로그아웃

## 2. 동선 MVP 기준

동선 MVP는 실제 길찾기 경로가 아니라 선택한 장소의 좌표를 순서대로 연결한 선으로 표시한다.

```txt
장소 A -> 장소 B -> 장소 C
```

Kakao 지도 위에는 위 순서대로 Polyline을 그린다.

## 3. MVP 전에는 구현하지 않음

- 영업 중 필터
- 실제 길찾기 API 기반 도보 경로 표시
- 커뮤니티 게시판
- 친구 기능
- 시간표 공유
- 댓글 / 대댓글

## 4. 구현하지 않음

- 학교 메일 인증
- 이메일 OTP 인증
- 소셜 로그인
- Google Maps
- Naver Maps

## 5. 한 줄 요약

```txt
MVP는 Kakao 장소 검색, 지도, 북마크, 리뷰, 혼잡도, 간단한 동선 공유까지만 구현한다.
```
