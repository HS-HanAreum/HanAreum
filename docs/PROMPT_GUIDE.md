# HS-Road AI 프롬프트 가이드

이 문서는 팀원이 ChatGPT, Codex, Claude Code 등 AI 코딩 도구에게 작업을 요청할 때 사용하는 양식을 정리합니다.

목표는 AI가 프로젝트 전체를 마음대로 수정하지 못하게 하고, **작은 범위의 작업만 안전하게 수행하게 하는 것**입니다.

---

## 1. 좋은 요청의 원칙

좋은 요청은 아래 내용을 포함합니다.

```txt
누가 작업하는지
어떤 기능을 만드는지
수정 가능한 파일은 무엇인지
수정하면 안 되는 파일은 무엇인지
완료 기준은 무엇인지
테스트 방법은 무엇인지
```

나쁜 요청:

```txt
리뷰 기능 만들어줘.
프로젝트 완성해줘.
오류 알아서 다 고쳐줘.
더 좋은 구조로 바꿔줘.
```

좋은 요청:

```txt
ReviewForm.tsx 파일에서만 리뷰 작성 UI를 만들어줘.
별점, 한 줄 평, 방문 시간대 선택이 있어야 해.
DB 저장은 아직 하지 마.
```

## 2. 기본 작업 요청 양식

```txt
[작업자]
이름:
담당:
브랜치:

[작업 목표]


[수정 가능 파일]


[수정 금지 파일]


[요구사항]


[금지사항]


[완료 기준]


[테스트 방법]

```

## 3. 예시 - 장소 카드 UI

```txt
[작업자]
이름: 박민재
담당: 장소 리스트 / 필터 UI
브랜치: feature/pmj

[작업 목표]
장소 검색 결과를 보여주는 PlaceCard UI를 만들고 싶습니다.

[수정 가능 파일]
src/components/places/PlaceCard.tsx
src/types/place.ts

[수정 금지 파일]
src/app/api/**
src/lib/**
supabase/schema.sql
.env
package.json

[요구사항]
- 장소명 표시
- 카테고리 표시
- 주소 표시
- 3-Dot 거리 표시 영역 추가
- 북마크 버튼이 들어갈 자리만 만들어두기
- UI 문구는 한국어

[금지사항]
- Kakao API 직접 호출 금지
- DB 연결 금지
- 패키지 설치 금지
- 다른 파일 수정 금지

[완료 기준]
- PlaceCard 컴포넌트가 렌더링된다.
- props로 받은 장소 정보를 화면에 표시한다.
- npm run lint에서 오류가 나지 않는다.

[테스트 방법]
npm run dev 실행 후 장소 리스트 화면에서 카드가 보이는지 확인
```

## 4. 예시 - 리뷰 폼 UI

```txt
[작업자]
이름: 오유민
담당: 리뷰
브랜치: feature/oym

[작업 목표]
리뷰 작성 폼 UI를 만들고 싶습니다.

[수정 가능 파일]
src/components/reviews/ReviewForm.tsx
src/components/reviews/RatingInput.tsx
src/types/review.ts

[수정 금지 파일]
src/app/api/**
src/lib/**
supabase/schema.sql
.env
package.json

[요구사항]
- 별점 선택 UI
- 한 줄 평 입력
- 방문 시간대 선택
- 저장 버튼
- 방문 시간대는 morning, lunch, afternoon, evening, night 중 하나
- 화면 표시는 오전, 점심, 오후, 저녁, 밤

[금지사항]
- DB 저장 기능 구현 금지
- 리뷰 테이블 구조 변경 금지
- 패키지 설치 금지

[완료 기준]
- 폼이 화면에 보인다.
- 입력값이 state로 관리된다.
- 저장 버튼 클릭 시 console.log로 입력값이 출력된다.

[테스트 방법]
npm run dev 실행 후 리뷰 폼에서 값을 입력하고 버튼 클릭
```

## 6. 에러 해결 요청 양식

```txt

[실행한 명령어]
예: npm run dev

[에러 메시지]
터미널 에러를 그대로 붙여넣기

[수정 가능 파일]


[수정 금지 파일]


[요청]
코드를 바로 수정하기 전에 원인을 먼저 쉽게 설명해줘.
수정이 필요하면 어떤 파일을 고쳐야 하는지 먼저 말해줘.
```

## 9. AI에게 시키면 안 되는 요청

```txt
프로젝트 전체 구조 개선해줘
DB까지 알아서 연결해줘
로그인 기능 추가해줘
카카오 API 연동까지 다 해줘
코드 전체 리팩토링해줘
더 좋은 라이브러리 추천해서 적용해줘
알아서 완성해줘
dev에 merge해줘
main에 push해줘
```
